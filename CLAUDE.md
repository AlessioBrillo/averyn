# CLAUDE.md

Averyn (codename): open-source, self-hostable an existing platform alternative. iOS + Android + Web. Pre-alpha; focus is **MVP-0, a reliable GPS tracking engine**. Read `docs/README.md` for the docs system, `docs/product/roadmap.md` for scope, `docs/design/TDD-0001-tracking-engine.md` for the active design.

## Layout

- `shared/{domain,tracking,metrics}`: Kotlin Multiplatform (jvm, android, iOS). Pure Kotlin, no platform deps. `shared/ios-umbrella` re-exports them as the `Shared` framework.
- `backend/`: Ktor modular monolith, one Gradle module, package per domain under `dev.averyn.backend`. Flyway SQL in `src/main/resources/db/migration`.
- `apps/android` (Compose), `apps/ios` (SwiftUI, project generated by XcodeGen), `apps/web` (React + TS + Vite; admin is a route area).
- `build-logic/`: convention plugins (`averyn.kmp-library`, `averyn.ktlint`). Versions only in `gradle/libs.versions.toml`.
- `tests/gps-fixtures/`: reference traces + expected results. `infrastructure/compose/`: local/self-host stack.

## Commands

```sh
# Windows: JAVA_HOME must point at JDK 21; Android SDK path in local.properties (git-ignored)
./gradlew check                                   # tests + ktlint, all modules
./gradlew :shared:domain:jvmTest :shared:metrics:jvmTest :backend:test
./gradlew ktlintFormat
./gradlew :apps:android:assembleDebug
(cd apps/web && npm run check && npm run build)   # lint (oxlint) + typecheck + vitest
docker compose -f infrastructure/compose/docker-compose.yml --env-file infrastructure/compose/.env up -d --build
```

iOS cannot be built on Windows; CI (macOS runner) verifies it. The Docker backend build sets `AVERYN_BACKEND_ONLY=1` so Gradle skips Android/iOS modules.

## Rules that matter

- Raw location samples are immutable; filtering only flags. No silent data loss; every drop is counted with a reason.
- Metrics are versioned (`algorithm_version`); a behavior change = new version + `docs/metrics/*.md` update. Never edit an existing version.
- The state machine in `ActivityState` must match the diagram in TDD-0001; change both together.
- Never log coordinates, tokens or user content. Private by default. See `docs/privacy/data-classification.md`.
- Hard-to-reverse decisions need an ADR (`docs/adr/`); accepted ADRs are immutable (supersede instead).
- PR titles: Conventional Commits. Tests ship with logic. No secrets in the repo.
- Don't scaffold ahead: later areas (maps, social, segments, watch) get code only when their milestone starts.
